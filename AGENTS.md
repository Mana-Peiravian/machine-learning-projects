# Coursework preservation

Original coursework is immutable: do not rewrite source, notebook cells/outputs, reports, data, weights, images or results.

Add/improve portfolio documentation, metadata and static assets only. Preserve original READMEs. Execute training, notebooks, downloads or output-producing applications only with explicit authorization and in isolated copies.

Trace claims to code/reports/artifacts. Never reproduce secrets or student identifiers. Review course policy, collaborators' permission and source rights before publication.

Check .portfolio/original-files.json hashes after documentation work. Use .portfolio/validate.py for generated-link checks. Do not commit, push or change hosting settings without user instructions.
